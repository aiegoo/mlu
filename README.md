# Deep Learning Mastery (MLU) 🧠

A comprehensive, structured approach to mastering deep learning using d2l.ai and modern frameworks.

## 🚀 Quick Start

### Use as Template Repository
1. **Click "Use this template"** on GitHub to create your own copy
2. **Clone your repository**:
   ```bash
   git clone https://github.com/yourusername/your-mlu-repo.git
   cd your-mlu-repo
   ```
3. **Get the bootstrap template**:
   ```bash
   git checkout bootstrap-template
   ```
4. **Run automated setup**:
   ```bash
   # Linux/Mac/WSL
   ./install.sh
   
   # Windows PowerShell
   .\install.ps1
   ```
5. **Start learning**:
   ```bash
   # Linux/Mac
   ./quick_start.sh
   
   # Windows
   .\quick_start.ps1
   ```

### Or Clone Directly
```bash
git clone https://github.com/aiegoo/mlu.git
cd mlu
git checkout bootstrap-template
./install.sh  # or .\install.ps1 on Windows
```

## 📚 What's Included

The **bootstrap-template** branch contains:

### 🛠️ **Automated Setup**
- **Cross-platform installation scripts** (Linux/Mac/Windows)
- **Smart environment detection** (conda vs pip)
- **GPU auto-detection** with CUDA setup
- **One-click activation** and quick start scripts

### 📖 **Learning Materials**
- **16-week structured roadmap** from basics to advanced topics
- **Comprehensive Jupyter notebook** with neural networks from scratch
- **d2l.ai integration** with progress tracking
- **Mathematics review** (linear algebra, calculus, probability)
- **Study guides** and resource compilation

### 🏗️ **Project Structure**
```
mlu/
├── 01_foundations/          # Math & ML basics
├── 02_ml_basics/           # Core ML algorithms  
├── 03_deep_learning/       # Neural networks
├── 04_computer_vision/     # CNNs & vision
├── 05_nlp/                # Language models
├── 06_advanced/           # Advanced topics
├── 07_projects/           # Hands-on projects
├── environments/          # Setup guides
└── resources/             # Study materials
```

### 🎯 **Learning Path**
- **Phase 1**: Foundations (Weeks 1-4)
- **Phase 2**: Deep Learning Fundamentals (Weeks 5-8)  
- **Phase 3**: Advanced Architectures (Weeks 9-12)
- **Phase 4**: Specialization & Projects (Weeks 13-16)

## 🎓 Learning Philosophy

This repository follows a **hands-on, implementation-first** approach:
1. **Understand by implementing** - Build neural networks from scratch
2. **Learn with d2l.ai** - Use the best interactive textbook available
3. **Practice with frameworks** - Master PyTorch and modern tools
4. **Build real projects** - Apply knowledge to solve problems
5. **Join the community** - Learn with others
